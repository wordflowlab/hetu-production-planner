# 制片筹备

发现当前启用包、同包摘要和精确作品能力，读取固定剧本与已有筹备。通过河图稳定CLI/MCP调用本包；不新增Codex插件或MCP连接。

按[专业流程](references/workflows.md)选择拆解、计划、改稿复核或交接；[操作地图](references/operations.md)仅作导航，参数以实际安装Schema为准。

准备工时与费用是声明估算；未知保持null，不以0补全。prepared和done不等于宿主选用、真实支付或现场验收。批次只计算单通道串行准备，不推断演员档期与最优排摄。

保留固定引文与来源索引。改稿追加新来源，先预览影响再复读；位移也需核对，不把结构检查当语义完整。保存携带CAS和原操作键，未知先回读原键，成功后读取确切修订。付费生成、外发、正文采纳与定稿分别按作者决定执行。
