# 河图制片筹备台

> 从固定剧本拆出制作需求，核对准备依赖与估算，按改稿影响接续美术、布景和视听工程。

## 简介

独立TypeScript／React河图插件。作者向Agent说明目标，在工作面审阅场次制作单、资源矩阵、准备批次与变更影响；机器业务通过稳定CLI/MCP完成。

## 快速上手

从河图插件中心取得固定运行包，安装启用后让Agent发现本包能力和包内Skill。可这样开始：

> 读取这一版剧本和已有筹备工程，拆出人物、地点、服装、道具及声音需求。先看哪些需要准备，列出依赖和未知估算；把美术需求交给美术设定台。改稿后只复核受影响的场次，不自动生成付费素材或定稿。

## 开发

Node.js 25，固定依赖归`package-lock.json`。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run test:machine
npm run test:ui
npm run package
```

固定正式宿主验收见[开发发布](docs/07-开发发布与维护.md)。

## 边界

准备工时与费用是明确声明的估算，未知保留为空，不代表真实报价、付费授权或现场排期。批次是单通道串行准备计划，不计算演员档期、劳动法规、采购或供应商交易。Fountain预览只识别明确场景标题，完整语义由Agent阅读。prepared表示工程声明的准备状态，不表示宿主已选用素材或作者定稿。
