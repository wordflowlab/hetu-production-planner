# 开发发布与维护

## 开发与验证

Node25、TypeScript、React18、Ajv与esbuild使用package-lock.json固定依赖。npm ci后依次构建、类型与单元检查，再用固定正式宿主执行CLI/MCP和Electron旅程。正常业务不依赖点击GUI，不直写.hetu。

acceptance-lock.json固定宿主版本、源码、归档摘要及本包内容摘要。scripts/accept-installed.py验证签名、公证和随包资源。HETU_ACCEPTANCE_APP显式选择本机隔离正式制品，HETU_REUSE_APP=1只在独立核验后使用；CI在干净runner安装/Applications/Hetu.app。外部共享安装路径不覆盖。

## 发布与生态

完整验收后固定源码、v0.1.0 Tag和GitHub Release，交付预构建tgz、归档SHA-256、解压包摘要、版本锁和验收回执。重新下载核验公开字节，再把同一提交及制品登记河图插件中心。不可变发行不覆盖附件。

专业功能与Schema归本包，宿主只做发现和公共数据能力。安装启用即可复用公开SDK，不新增专业动作授权层；作品连接、内容外发及作者决定分别核验。兼容升级保留旧修订，不静默裁字段。

## 研究与许可

逐个克隆Trelby及Fountain为research base，记录提交、重点文件摘要和许可。Trelby GPL源码仅做对照，不复制进Apache实现；Fountain协议概念与独立解析区分。公开SaaS页面只记录实际取得范围，不据营销主张声称运行通过。原始来源归docs/research。
