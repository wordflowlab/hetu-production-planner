# Skill与机器接续

## 发现与接续

河图安装启用后，在同一Codex会话重新查询hetu.plugins.inspect，按精确作品和management_ref发现hetu.plugins.capabilities。通过稳定invoke调用skills.read读取production-planner；新包摘要改变时重新发现，不为此安装Codex插件或额外MCP服务。

入口见[SKILL](../skills/hetu-production-planner/SKILL.md)，执行前参数以实际Schema为准；[操作地图](../skills/hetu-production-planner/references/operations.md)由清单生成。方法按目标分流至[专业流程](../skills/hetu-production-planner/references/workflows.md)。

## 默认旅程

读取固定剧本及已有工程，报告实际已读范围；明确标题预览可以辅助拆场，人物、道具、动作和语义关系由Agent核对。补齐制作需求和显式依赖，未知工时与费用保持null。计算缺口与批次，向作者呈现实际结果。

改稿时追加新来源，先看preview_source_change再复读变化或位移场次；不得将坐标不变当作语义一致。按固定场次和专业依据交给已安装美术、布景和视听包，回读下游成果；正文参考稿可独立准备，采纳和定稿另行决定。

## 方法边界

本包不生成图片、视频或语义抽取结果，不自动发送资料、消费预算或执行交易。工时表示准备任务的声明估算，不是成片时长或演员档期。数据大时按固定summary和分块回读，不能把截断内容冒充已读全文。未知先回读原操作，不换键重写。

导入原文件后先回读实际固定文稿，使用其返回摘要和字节建立范围；TXT到Markdown的合法转义不应被原文件坐标替代。标题中的转义连字符只可调整展示，quote保持原字节。
