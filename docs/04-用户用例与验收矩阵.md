# 用户用例与验收矩阵

## 用户用例与验收出口

| 编号 | 场景 | 必须验证 |
| --- | --- | --- |
| PP-01 | 新建与已有稿 | 无GUI建立工程，固定原稿并读取已有成果 |
| PP-02 | Fountain | 中文、CRLF、BOM、强制场景标题、无标题、注释与明确解析边界 |
| PP-03 | 需求矩阵 | 同一资源多场复用、不同单位不合并、空资源与重复关联 |
| PP-04 | 实体与素材 | 人物类型、作品身份、错误来源、来源索引越界拒绝 |
| PP-05 | 依赖 | 自环、间接环、重复依赖、跨批倒置与缺失任务 |
| PP-06 | 准备状态 | 已完成前置约束、阻塞原因、声明prepared与正式资产选用区分 |
| PP-07 | 估算 | 未知工时／费用、零值、容量不足、安全整数、单币种 |
| PP-08 | 改稿 | 原范围不变、位移、删去、中文字节边界、显式传递影响 |
| PP-09 | 意见 | 固定场次、需求或任务改变后stale，旧版本保持 |
| PP-10 | 专业交接 | 同场次对美术／导演／视听的不同投影和固定依据 |
| PP-11 | 原操作 | 同键同输入、同键异参、写后丢响应、unknown不重发 |
| PP-12 | 并发 | CAS冲突保留输入、人工与Agent编辑后比较回读 |
| PP-13 | 生命周期 | 同会话安装、Skill读取、停用、启用、卸载重装后旧修订可读 |
| PP-14 | 实际界面 | 浅暗、宽窄、键盘、减少透明度、取消、错误、关闭重开与未保存输入 |
| PP-15 | 完整接续 | 固定剧本→筹备→美术和布景→新版影响→宿主候选→下一轮 |
