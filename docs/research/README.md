# 研究依据与取舍

固定源码与重点文件摘要见[sources.json](sources.json)。Trelby分别组织场次和地点报告，提示制作需求应能回到具体场次，地点复用不应靠名称创建第二套正典。Fountain解析器与格式用例用于核对标题识别边界，本插件只做有界预览，不声称完整Fountain解释器。Trelby GPL代码不复制，未执行上游安装、构建或模型调用。

公开SaaS页面实际取得情况见[saas.json](saas.json)，失败页面不作为功能依据。河图不复刻团队交易与采购系统；固定来源、专业需求与可回读成果是采纳范围。费用和工时按声明前提计算，不自动作真实承诺。
